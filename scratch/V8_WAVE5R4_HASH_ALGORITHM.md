# Delivery Proof Hash Algorithm

1. **Source Data:** The raw HTML output generated by Astro at build time in the `dist/` folder.
2. **Strip Scripts:** All `<script>` tags and their contents are removed via regex.
3. **Strip Styles:** All `<style>` tags and their contents are removed via regex.
4. **Strip Comments:** All HTML comments `<!-- ... -->` are removed.
5. **Whitespace Normalization:** All consecutive whitespace characters (including newlines and tabs) are collapsed into a single space.
6. **Trimming:** Leading and trailing whitespace is removed.
7. **Hashing:** The normalized string is hashed using Node's native `crypto.createHash('sha256')`.
8. **Output:** The hash is converted to a hexadecimal string.

This ensures that minor formatting changes or dynamic script injections (which don't alter the core semantic structure, text, links, or schema) do not break the parity validation.
